# 配送时段日期筛选

配送时段页进入时默认显示北京时间本周，周一至周日均包含。保留全部原始时段数据，筛选只控制管理列表展示，不改变预约、容量、订单或配送安排。

日期范围下拉框支持本周、本月、当天、全部时段及自定义，开始与结束日期使用现有 Field 和原生日期控件。日期摘要采用 `2026年11月02日 — 2026年11月08日` 格式，显示匹配时段数量。手动输入的日期匹配标准范围时自动识别；范围重叠时优先识别当天、本周、本月、全部，明确通过下拉选择的项保持原选择。

校区和日期同时生效。“全部时段”动态使用当前校区未归档时段的最早、最晚日期；列表刷新或校区变化会重新计算。无时段时日期留空，不虚构日期。相对范围每分钟及页面恢复可见时按北京时间更新，自定义范围保持固定。空值或起止倒置显示关联字段错误。

修改文件：`src/admin/logistics.tsx` 接入筛选，`src/admin/slot-date-filter.tsx` 管理控件与范围状态，`src/lib/slot-date-range.ts` 处理日期计算，`src/styles.css` 使用现有风格和自适应网格。测试文件与移动端 Playwright 配置同步更新。
