# DormPrint 加载与动效接入规范

更新：2026-10-30。实施依据为《前端加载与动效统一规范 Prompt》及用户确认：保留现有 UI/UX、布局、业务文案、品牌、路由与权限，只接入动画及真实任务反馈链。对话演示的排版、样式和示例文字不作为产品界面模板。

## 共享参数

| 用途 | 参数 |
|---|---|
| 按下、颜色、边框反馈 | 100ms |
| 菜单、辅助提示、局部出现 | 140ms |
| 按需页面内容淡入 | 150ms；框架固定，不随数据刷新重复播放 |
| 原有折叠、侧栏 | 折叠220ms；侧栏沿用200ms，退出保护保留220ms；保留原空间关系 |
| 普通弹窗进入 | 窗口320ms ease-in-out，遮罩300ms linear，同步开始 |
| 普通弹窗退出 | 180ms ease-out |
| 普通操作圈 | 约200ms后出现；锁定与状态立即生效，快速完成不强播 |
| 选择文件入口 | 原文案、宽高和明暗不变；350ms后才在原提示位显示辅助信息 |

变量在 `src/components/motion.css`，生命周期参数在 `presence.ts`。原有管理导航、窗口CSS样式复用，新增样式仅作用于动效与临时反馈。无大型动效依赖、无全页缩放、弹簧、数字滚动或滚动揭幕。

## 组件与状态

- `Button busy/busyLabel`：同步禁用，延迟替换原动作图标；原内容占位保持宽度。账号多表单使用 `busyTarget` 将圈限制到触发控件，其余控件沿用原有禁用策略。
- `TaskStatus`：具体任务文案、局部圈、长等待说明；离线显示网络状态，停止普通圈。只用于真正繁忙，不用于待人工或待用户选择。
- `Progress`：真实完成量为0–100；未知值、非有限值不设置 aria-valuenow，不伪装为0%。图片环表示完成弧段；不确定模式使用独立循环。未知环/骨架在隐藏页面暂停，减少动画时改静态反馈。
- `ResourceSkeleton`：卡片、表格、摘要、时间线、统计、资料、优惠券、预览纸张八类，容器统一播报一次；已知标题、文件名、搜索框和本地表单保留。
- `RefreshStatus`：已有当前有效数据时保留原内容；刷新失败保持页面内错误及重试，不误报空数据。
- `MotionFold`：原有FAQ/展开内容由统一状态控制，箭头同步；关闭内容 inert/aria-hidden。现有段落字体、行高和边距保留。

## 资源与异步所有权

`planResources` 只请求当前页面需要的资源。首页/帮助不请求无关私有订单；订单结果与配置、地图、时段按区独立到达。`Provider.resources` 记录资源身份、初次/刷新、有效数据和错误。

资源身份包含当前身份代际、端和请求URL/查询条件。`LatestTask` 保证旧查询不覆盖新查询；A→B→A时只复用仍拥有当前资源的请求，已失去所有权的旧任务必须重新开始。首次、成功空数据、首次失败、刷新失败分别呈现。当前配置尚未就绪时提供安全空配置并限制上传/提交；同一有效配置的刷新继续保留可用内容。

`useGrowthResource` 区分 loading 与 refreshing，切换路径/身份立即隐藏旧数据，保留同路径有效数据；权限错误清除旧内容。重复读取合并，隐藏页不增加轮询，恢复可见/联网时核实当前状态。表单初次赋值与刷新分开，未保存输入不因刷新重置。

## 窗口完整生命周期

`usePresence` 支持打开、进入、打开、退出、移除，取消旧定时器/动画帧，动态响应减少动画。`overlay-stack` 按栈分配Esc、焦点与背景锁；关闭窗口立即不可操作，退出完成后才释放滚动/背景。焦点返回触发位置，快速重开继承合理触发点；无触发点时使用可用的页面位置。

条件挂载的旧窗口由不可操作的短暂DOM快照完成退场；快照保留当前透明度及画布内容，避免进入中关闭时闪成全亮。身份失效立即隐藏私有内容；快照不承载事件处理或业务取消。减少动画、计时器兜底、节点移除均能可靠清理；最后一层关闭后的观察器不会再次锁住背景。

## 文件与最终输出链

合法文件立即入队，排队/读取/传输/服务端确认/处理/就绪分开。文档行条与图片图标上的环各只显示一处主要进度；已就绪/待选纸张不循环。DEMO本地读取没有网络百分比，也不提供假Office转换。

XHR适配保留同源凭据、CSRF、幂等键、统一错误、AbortSignal、身份失效取消。字节达到100%后切到等待服务端确认，不显示成功。重试按是否已有assetId选择传输或处理；A4转换保留相同文件和幂等键。移除/卸载阻止旧回调复活条目；未知上传结果保留可核实、可重试的原图和信息，不声称后端任务已取消。

PDF.js向隔离画布渲染，当前版本完成后才提交到可见画布；翻页期间显示当前页和目标页，快速换文件/翻页/关闭会取消或淘汰旧任务。最终PDF、预览、报价与提交独立反馈；配置、身份、内容和报价版本不满足时不能提交。未知价格显示“—”，原有PDF与金额确认规则继续执行。

## 提交与线下结果

`ActionLock` 在异步前生效。网络失去响应、5xx/超时、不可确认的成功响应按结果待核实处理；明确4xx拒绝仍显示具体原因。未知结果保留原幂等键；订单提交未知时提供现有订单查询入口，不重新生成成功结果。生产与配送只有服务端明确确认后才更新完成态；调用系统打印仍需人工确认实际出纸。SMTP受理、导出申请与最终投递/可下载分开。

## 验证入口

- 单元/行为：`npm test`。
- 正式构建：`npm run build`；明确演示构建：`npm run build:demo`（均写dist，后者覆盖前者）。
- 系统Chrome桌面/移动回归：`npm run test:e2e -- --config playwright.motion.config.ts`；该配置自动准备普通演示服务和独立真实请求模式服务。真实请求模式用例使用显式HTTP拦截夹具，不表示后端联调。
- 页面、剩余契约与证据分别见同目录QA记录及覆盖表。
