# 后台分级导航实施

用户已授权直接优化现有后台导航；保留暖棕品牌、已有路由及能力过滤。

## 结构与行为
- 工作台直达；一级分组按订单与生产、配送管理、客户与优惠、系统与团队排序；个人账号保留为独立工具入口。
- 所有原有二级功能保留，各只属于一个分组。一次展开一组，可手动收起当前分组。
- 详情页匹配所属入口；路由变更自动展开分组。只对子链接设置 aria-current，分组按钮使用 aria-expanded/aria-controls。
- 收起内容设 inert/aria-hidden，键盘不能进入隐藏链接；mustChangePassword 仅保留个人账号，能力不足的空分组不显示。
- 220ms grid 收展与箭头旋转，支持快速反向切换；减少动态效果偏好取消空间动画。

## 实施
1. 新建 src/admin/navigation.ts：分组、入口、最长有效路径匹配和可见分组；tests/admin-navigation.test.ts 覆盖路径/权限/顺序/完整性，先失败再实现。
2. 修改 src/components/layouts.tsx：单一展开状态、路由自动定位、语义化二级菜单；新建 src/admin/navigation.css 限定样式，不改其他端布局。
3. 更新 tests/e2e/frontend.spec.ts，使已有导航测试先展开所属一级菜单，添加折叠互斥、隐藏链接和手机导航场景。
4. 实际运行 Vitest/构建；使用内置浏览器验证桌面与手机的展开/收起、唯一高亮、详情定位、键盘与动画，保存截图。CLI E2E 如仅发现用例，不宣称执行矩阵通过。
