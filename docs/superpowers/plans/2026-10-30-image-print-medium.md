# 图片上传后选择纸张

用户明确修改既有逻辑：图片不再固定归类为5寸照片。图片上传成功后弹出A4/5寸照片纸选择；多图分别选择，取消选择可回文件列表继续操作，未选纸张不能进入设置/报价。

- 复用现有 Modal、文件列表及A4/照片设置。列表中保留更换纸张入口，并说明切换会重置该图片打印参数。
- 区分原始图片来源与当前打印服务。保留内存中的原图/File/assetId，切回照片不会使用A4 PDF作为原图。
- A4路径：浏览器按EXIF方向解码并完整等比居中生成单页A4 PDF（10mm安全边距），默认彩色单面，可继续改颜色/面数/份数。真实模式将PDF作为普通PRINT_SOURCE上传，沿用现有DOCUMENT preparation契约；不新增后端接口。
- 照片路径：沿用既有照片裁剪、校准、份数和照片单价。A4图片按实际A4纸张计费并计入满量，照片纸不计入A4满量。
- 切换纸张清除旧预览产物/检查数据；异步转换及上传遵守身份代次，不在身份变化后写入旧转换。
- 更新上传提示、帮助说明、FileIcon及路由守卫，保证直接打开设置/结算也不能绕过纸张选择。

实施文件：lib/image-print.ts、types.ts、domain.ts、artifacts.ts、customer/upload.tsx、settings.tsx、help.tsx、components/ui.tsx；新增image-medium.css。
验证：先运行未选择状态回归；再补PDF尺寸/图片保留/纸张切换/独立计价及混合订单测试，完整Vitest/构建。内置浏览器实际上传PNG，选择A4并生成最终PDF，再检查照片路径、多图队列、取消/重选和手机布局。真实上传/转换服务依赖后端联调，不模拟生产API成功。
