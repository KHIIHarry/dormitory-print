# 配送时段日期筛选实施计划

**目标：** 进入配送时段页默认显示北京时间本周（周一至周日），支持当天、本周、本月、全部与自定义日期范围。

**方案：** 复用现有校区筛选、Field 和原生日期输入框；在已加载的时段列表上按配送日期筛选，起止日期包含边界。独立日期工具处理北京时间、跨月跨年、闰年和快捷范围识别。日期摘要显示中文年月日。

**交互约定：** 快捷范围下拉框加开始、结束日期；手动修改日期自动识别当天、本周、本月或全部，否则显示自定义。明确选择的快捷项在范围重叠时保持原选择。“全部”按当前校区最早至最晚的未归档时段动态计算；无数据时日期为空。日期缺失或倒置时给出行内提示。日期与校区共同过滤；无结果时提供切换范围的提示。新建、编辑、归档后的列表更新继续使用当前筛选。

**范围：** 仅修改管理端时段列表，不改预约容量、历史订单或后端接口。

- [x] 在 `tests/e2e/slot-date-filter.spec.ts` 挂载真实 Slots 组件，先验证默认周筛选失败，再实现 `src/admin/slot-date-filter.tsx` 并接入 `src/admin/logistics.tsx`；CSS 沿用现有样式，手机分行。
