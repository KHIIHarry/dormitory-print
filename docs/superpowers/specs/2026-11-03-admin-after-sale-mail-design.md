# 售后单管理员邮件通知

新增 `ADMIN_AFTER_SALE_CREATED` 非安全类邮件模板，默认启用，可在现有邮件模板页面编辑、预览、试发、停用和恢复默认。复用现有邮件的 shell、信息表格、提示区、暖棕按钮及链接回退，保持品牌样式一致。

内容包含售后单号、订单提取码、申请来源、责任类型、退款/重做诉求、客户昵称、脱敏联系电话和申请原因。退款、换材料等具体问题按用户填写的申请原因原文保留，并在 HTML 中转义。按钮进入 `/manage/after-sales/{id}`；邮件说明申请仍待审核，不表示已批准或已退款。

客户或管理员成功创建售后单时，在同一事务中为启用且有 `payment.manage`、`*` 或超级管理员权限、邮箱已验证的 ADMIN 员工创建邮件任务。以售后单和员工 ID 去重；邮件入队失败不回滚售后单。沿用现有邮件队列与 SMTP 发送机制，不新增数据表。

同步后端模板、演示模板及示例变量。通过 PostgreSQL 验证创建触发、收件权限、去重、停用、事务回滚、内容转义及实际本地 SMTP 接收；前端验证预览和构建，并检查桌面/窄屏邮件截图。
