# 打印、装订和配送价目配置

按用户两张截图保留现有暖色卡片和左右价目行。帮助页展示五项打印价格、左上角单钉、左侧双钉和配送费；单位依次为张、份、次。删除价目下方旧提示。每项明确配置为 0 时显示红色“免费”；null/留空显示“暂未配置”，加载和失败沿用现有状态。

后台在同一价格分区增加配送费输入（元/次），装订输入统一为元/份。沿用整数分存储、NumberInput、版本检查、预览保存与审计。每份装订仍对应完整的一册，不改变份数与装订张数限制。

prices.delivery 保存每单一次配送费。现有 JSON 配置缺少该键时默认 0，兼容历史免费配送；显式清空则为未配置并阻止新报价。报价保留商品行小计与优惠分摊，配送费不参与商品优惠，totalCents = subtotalCents - discountCents + deliveryFeeCents。订单沿用报价快照，配置调整不改写历史订单。

实现方式采用现有价格分区和独立 deliveryFeeCents。单独新增配送配置分区会增加保存操作；把配送混入商品行会改变优惠适用范围，均无需采用。

验证包括配置保存及零值/空值、收费报价/优惠/历史快照的 PostgreSQL 集成测试，前端报价校验与配置单元测试，以及 320–1440px Chromium/WebKit 页面和输入边界回归。桌面浏览器模拟不能代表真实 iPhone。
