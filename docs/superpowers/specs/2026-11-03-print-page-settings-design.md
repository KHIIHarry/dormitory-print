# 打印页码设置

用户已确认以下交互并要求开始修改。

- 按每个分段的实际页数判断：单页自动改为单面、无翻转，双面禁用；恢复多页后允许选择双面，但不自动切回双面。
- 上传、恢复草稿及修改页码均应用同一规则。服务端生成产物和报价前也校正单页设置。
- 高级分段中的跳过页输入框替换为“选择跳过打印页”按钮，打开选择器列出当前文件全部页码。
- 已分配页面仍显示，置灰不可勾选，标注所属分段。其余页面可勾选；确认保存，取消不修改。
- 已跳过页面后来加入打印分段时，取消这些页面的跳过状态，避免同时打印和跳过。
- 每页必须分配到打印分段或明确跳过，否则禁止进入最终预览。沿用现有分配校验和视觉样式。
- 验证单页计价、真实服务端 PDF/报价，以及桌面和移动端的完整操作。
